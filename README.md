ATM Simulation in C++

A simple console-based ATM simulation program written in C++.

Features
PIN authentication
Check account balance
Deposit money
Withdraw money
Menu-driven interface
Technologies Used
C++
Object-Oriented Programming
How to Run

Compile the program:

g++ atm.cpp -o atm

Run the executable:

./atm
